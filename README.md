# XOS Alpha

A Debian 13 (trixie) based live operating system for 64-bit Intel/AMD PCs, with its own boot menu, boot splash and light "porcelain / graphite / crimson" desktop (Openbox, Tint2, Rofi, PCManFM).

Status: **alpha, ISO not yet built or boot-tested by the maintainer.** Everything is built remotely by GitHub Actions. See `docs/TESTING.md` for what has and has not been verified.

- Build in the cloud: `docs/GITHUB-ANDROID.md`
- Write to USB with Rufus: `docs/RUFUS-USB.md`
- Local build on Linux: `docs/BUILD.md`
- Architecture: `docs/ARCHITECTURE.md`
- Limits: `docs/KNOWN-LIMITATIONS.md`

Default session is a **non-persistent live session**. It never partitions or formats internal drives automatically.

Shortcuts: Super+Space launcher, Super+E files, Super+T terminal, Super+D show desktop, Alt+F4 close, Alt+Tab switch, Super+Left/Right snap, Super+1..4 workspaces, Print screenshot.
